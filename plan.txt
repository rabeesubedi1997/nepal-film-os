# SECTION 2: PROJECT OVERVIEW

Nepal Film OS is a Film Production Management SaaS web application built specifically for the Nepali film industry.

## What It Replaces
- WhatsApp groups for coordination
- Excel sheets for schedules and budgets
- Paper call sheets
- Manual expense tracking
- Fragmented communication across departments

## What It Provides
A centralized, real-time, role-based film production management platform for the Nepali film industry from pre-production to post-production.

# SECTION 4: MULTI-TENANT ARCHITECTURE

- One platform, multiple film workspaces
- Each film = isolated workspace (film_id scoped on all queries)
- Users belong to multiple films with DIFFERENT roles per film
- Super Admin manages all films across the platform
- Scale target: 100+ films simultaneously
- Redis caching for dashboard data, proper DB indexing on film_id

# SECTION 5: USER ROLES (PER FILM, NOT GLOBAL)

## Key Architecture Rule
A user role is PER FILM, not global.
Ram Shrestha can be Director on "Prem Geet 4" AND Production Manager on "Loot 3" AND Crew on "Chhaka Panja 5".
This is managed via the film_users pivot table.

## Roles
1. Super Admin       - Platform owner. Sees all films. Manages subscriptions and modules.
2. Producer          - Film owner. Full access to their film workspace.
3. Director          - Creative lead. Schedule, script, shot list, progress.
4. Production Manager - Operations lead. Budget, crew, logistics, call sheets.
5. Department Head   - HOD for a specific dept (costume, camera, makeup, etc.)
6. Crew / Staff      - Limited access. Own call sheet, check-in, progress upload only.

# SECTION 6: COMPLETE MODULE LIST (18 MODULES)

Modules are toggled per film by Super Admin via film_modules table.

MODULE 1: SHOOTING SCHEDULE
- Day-wise schedule view
- Stripboard (drag and drop visual scene ordering - industry standard)
- Scene breakdown per day, location assignment, call time per department
- Scene status: not started / in progress / completed / postponed
- Day Out of Days (DOOD) - cast availability matrix across all shoot days

MODULE 2: SCRIPT AND BREAKDOWN (NEW)
- Script upload (PDF/FDX import)
- Scene-by-scene breakdown: cast, props, wardrobe, SFX, vehicles, extras count
- Color-coded element categories (industry standard)
- Script revision tracking and version history
- Script sides generation per actor per day
- Watermarked PDF export per cast/crew member

MODULE 3: SHOT LIST AND STORYBOARD (NEW)
- Shot list per scene with: shot type, camera angle, lens, movement, description
- Storyboard image upload per shot
- Link shots to scenes, export shot list as PDF

MODULE 4: CAST AND CREW MANAGEMENT
- Actor and crew profiles with photo
- Department grouping with HOD assignment
- Availability calendar, Day Out of Days tracking
- Contact database (phone, email, WhatsApp)
- Emergency contacts, contract status
- Invite crew via email/SMS

MODULE 5: EXPENSE TRACKING AND BUDGET
- Department-wise budget definition
- Real-time expense entry with receipt image upload
- Full categories: Pre-production, Camera, Lighting, Art, Costume, Makeup, Location, Travel, Food, Crew/Cast Payments, Post-production, Marketing, Misc
- Budget vs actual dashboard with visual charts
- Expense approval workflow (submit -> approve -> paid)
- Purchase Order (PO) tracking
- Export to Excel/PDF

MODULE 6: PROGRESS TRACKING (REAL-TIME)
- Photo/video upload from set
- Scene status updates
- Daily progress log (scenes completed, pages shot, hours worked)
- Director notes per scene
- Activity timeline feed
- Planned vs actual scene comparison

MODULE 7: CALL SHEET
- Auto-generate from schedule and cast/crew data
- Individual department call times
- Weather, emergency contacts, catering info
- Watermarked PDF generation
- Share via WhatsApp, Email, in-app notification
- Track who has acknowledged the call sheet

MODULE 8: LOCATION MANAGEMENT
- Location database with photos and GPS coordinates
- Permit status tracking (pending/approved/rejected)
- Contact person for location, shoot history
- Parking, logistics, and nearest facilities notes

MODULE 9: WARDROBE AND COSTUME (NEW)
- Costume catalog per character
- Scene-by-scene costume assignment with continuity photos
- Costume status (ready / in alteration / missing)

MODULE 10: CONTINUITY TRACKING (NEW)
- Per-scene continuity records (wardrobe, hair, makeup, props, set)
- Continuity photos with scene-to-scene comparison notes
- Script supervisor notes

MODULE 11: TASK MANAGEMENT (NEW)
- Tasks with due date, assigned to, priority
- Department-level task boards
- Task status: todo / in progress / done
- Linked to scenes or modules, overdue alerts

MODULE 12: TIME SHEETS (NEW)
- Daily check-in/check-out (manual or QR code scan)
- Auto-calculate hours and overtime
- Department-wise summary, export for payroll

MODULE 13: DAILY PRODUCTION REPORT - DPR (NEW)
- Auto-generated from day's data (schedule, progress, expenses, time sheets)
- Scenes/pages scheduled vs completed, crew count, total hours, daily expenses
- Director and PM notes
- PDF export in industry standard format
- Auto-sent to producer at end of day

MODULE 14: DOCUMENT LIBRARY (NEW)
- Upload contracts, permits, NDAs, licenses with folder structure
- Role-based access per document
- Watermarked PDF download (viewer name + timestamp)
- Version history and expiry alerts

MODULE 15: IN-APP MESSAGING (NEW)
- Direct messages, department group chats, producer announcements
- File and photo attachments, pinned messages, read receipts
- MVP: polling; v2: WebSockets

MODULE 16: NOTIFICATIONS (NEW)
- In-app notification center
- Email (call sheet sent, expense approved, task assigned)
- WhatsApp and Sparrow SMS (Nepal)
- User notification preferences

MODULE 17: NEWS AND INDUSTRY FEED
- Nepal + global film news via RSS
- Categories: casting, releases, box office, celebrity, awards
- Nepal: OnlineKhabar, MyRepublica, Setopati, Kathmandu Post, xnepali.net, cinepatra, reelnepal, RONB
- Global: Variety, Hollywood Reporter, Deadline, IMDb News

MODULE 18: SERIES AND EPISODE MANAGEMENT (NEW)
- Create series with multiple episodes
- Each episode has its own schedule, script, budget
- Cross-episode cast/crew management and series-level budget aggregation

budgets: id, film_id, department_id, category, budgeted_amount, currency

documents: id, film_id, folder, document_name, file_path, file_type, file_size, access_roles JSON, uploaded_by, version, expires_at, is_watermarked, is_confidential

messages: id, film_id, sender_id, group_id, receiver_id, message, attachments JSON, is_announcement, is_pinned

# SECTION 9: LARAVEL BACKEND ARCHITECTURE

## Middleware Chain (every film API request)
Request -> Authenticate (Sanctum) -> FilmAccessMiddleware -> FilmRoleMiddleware -> ModuleEnabledMiddleware -> Controller

## Key Middleware Files
- FilmAccessMiddleware.php       checks film_users: does this user belong to this film?
- FilmRoleMiddleware.php         checks role within film, injects into request
- ModuleEnabledMiddleware.php    checks film_modules: is this module enabled?
- SuperAdminMiddleware.php

## API Routes
/api/auth/...
/api/super-admin/...                    [SuperAdminMiddleware]
/api/films/{film}/schedule              [FilmAccessMiddleware + FilmRoleMiddleware]
/api/films/{film}/scenes
/api/films/{film}/script-breakdown
/api/films/{film}/shot-list
/api/films/{film}/cast-crew
/api/films/{film}/expenses
/api/films/{film}/budget
/api/films/{film}/call-sheets
/api/films/{film}/locations
/api/films/{film}/progress
/api/films/{film}/wardrobe
/api/films/{film}/continuity
/api/films/{film}/tasks
/api/films/{film}/timesheets
/api/films/{film}/dpr
/api/films/{film}/documents
/api/films/{film}/messages
/api/films/{film}/notifications

## Key Services
- CallSheetService.php       auto-generate call sheets
- PDFExportService.php       all PDF generation via DomPDF/Snappy
- DPRService.php             auto-generate daily production report
- WhatsAppService.php        Twilio/Sparrow SMS integration

## Scheduled Jobs
- GenerateDailyCallSheet.php     runs each morning

# SECTION 10: REACT FRONTEND ARCHITECTURE

## Role-Based Layouts
- SuperAdminLayout.jsx        all films, platform controls
- ProducerLayout.jsx          full sidebar, budget approval buttons
- DirectorLayout.jsx          schedule/script/shot list focus
- ProductionManagerLayout.jsx budget/crew/logistics focus
- DeptHeadLayout.jsx          own department view
- CrewLayout.jsx              call sheet + check-in only

## Auth Flow
1. User logs in, receives Sanctum token
2. User selects film from "My Films" list
3. API returns: { film, role, permissions, enabled_modules }
4. React stores in authStore
5. Router renders appropriate Layout based on role
6. RoleGuard and ModuleGuard protect routes/components
7. All API calls include film_id + auth token

## State (Zustand stores)
- authStore: user, current film, role, permissions
- filmStore: film context, enabled modules

# SECTION 17: SECURITY REQUIREMENTS (OWASP)

- All API routes protected by Sanctum token (no public endpoints)
- Role-based access enforced at controller + Policy level, not only frontend
- film_id scope enforced on EVERY database query (prevent cross-tenant leakage)
- File uploads: type validation, size limits, malware scanning
- Document watermarking to prevent unauthorized sharing
- Rate limiting on all API endpoints
- Input validation and sanitization (SQL injection, XSS prevention)
- HTTPS enforced via Cloudflare SSL
- Full audit trail for all sensitive actions with old/new values
- 2FA optional for Super Admin and Producer roles
- Session expiry and token rotation
